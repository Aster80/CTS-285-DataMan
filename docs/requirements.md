
# DataMan Module 5 Traceability

## Product slice

Two-attempt answer flow.

## Requirement

Students should be able to answer a practice question and receive
feedback while following the two-attempt limit.

## User story

As a student, I want two opportunities to answer a practice
question so that I can learn from an incorrect answer.

## Acceptance criterion AC-M4-01

Reconstructed from available Module 4 carry-forward evidence:

- A correct answer completes the question.
- An incorrect first answer allows one more attempt.
- An incorrect second answer reveals the correct answer.
- Progress is preserved between requests.
- The two-attempt rule is enforced in reusable business logic.
